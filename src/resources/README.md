# Vendored AutoIt UDFs

`ExtMsgBox.au3` is a vendored copy of Melba23's [Extended Message Box UDF](https://www.autoitscript.com/forum/topic/109096-extended-message-box-new-version-16-feb-24/). Its header also credits photonbuddy, YellowLab, and KaFu.

`StringSize.au3` is a vendored copy of Melba23's [StringSize UDF](https://www.autoitscript.com/forum/topic/114034-stringsize-m23-new-version-16-aug-11/). Its header also credits trancexx and Larrydalooza.

Melba23 states in the AutoIt forum signature attached to these UDF discussions that their own forum code is public domain and available without restriction. The original headers are retained for attribution. The exact upstream revisions represented by these copies are not recorded in the repository history, so future updates should record the source URL, retrieval date, and upstream version or checksum here.
